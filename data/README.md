# Datasets

The current project uses generated scene points and `sample.xyz` for reproducible tests. These are synthetic examples, not measurements from a physical LiDAR.

The exact scene geometry, ROS2 topics, parameters, and validation scope are documented in [`../docs/DATA_PROVENANCE.md`](../docs/DATA_PROVENANCE.md).

When a real and publishable dataset becomes available, place it under `real/` and document its source, license, sensor, coordinate frame, units, and permission to redistribute. Keep real and synthetic data separated.
